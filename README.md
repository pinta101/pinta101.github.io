# 🐸 Rana Hop — PWA

## Archivos incluidos
- `index.html` — El juego completo
- `manifest.json` — Configuración de la PWA
- `sw.js` — Service Worker (funciona offline)

## Cómo subir a la web

### Opción 1: GitHub Pages (gratis)
1. Crea una cuenta en github.com
2. Crea un repositorio nuevo
3. Sube los 3 archivos
4. Ve a Settings → Pages → Branch: main → Save
5. Tu juego estará en: `https://tu-usuario.github.io/tu-repo`

### Opción 2: Netlify (gratis, muy fácil)
1. Ve a netlify.com
2. Arrastra la carpeta con los 3 archivos
3. ¡Listo! Te dan un enlace público al instante

### Opción 3: Vercel (gratis)
1. Ve a vercel.com
2. Importa desde GitHub o sube los archivos

## Instalar como app en el móvil
1. Abre el enlace en Chrome (Android) o Safari (iPhone)
2. Toca el menú → "Añadir a pantalla de inicio"
3. ¡Ya tienes la app instalada y funciona sin internet!

## Notas
- El juego funciona 100% offline después de la primera visita
- Compatible con Android e iOS
- No necesita ninguna instalación de APK
